# Manuales del tablero PGCB

Documentación de usuario e instalación del tablero de pronóstico de demanda y alertas de déficit eléctrico (PGCB, Bangladesh).

- Manual de usuario del tablero: https://drive.google.com/file/d/1d1wCS_ddQsxK0Zn7dab4A7eK9ArxrrmL/view?usp=sharing
- Manual de instalación del tablero: https://drive.google.com/file/d/1DRtW6FRrqkTBAWWBSjGQwsuPnS7P1aqG/view?usp=sharing

## Despliegue

- Tablero: http://54.197.163.213:8050
- API (documentación): http://54.197.163.213:8001/docs

La IP pública cambia si la instancia EC2 se detiene y se vuelve a iniciar (Learner Lab).

- El manual de usuario explica cómo usar los controles, leer los indicadores y las alertas del tablero, con un ejemplo.
- El manual de instalación explica cómo desplegar la API y el tablero con Docker en un servidor Linux (EC2).
